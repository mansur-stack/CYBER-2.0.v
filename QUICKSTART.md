## 🎯 Saytni Ishga Tushirish (3 ta Qulay Usul)

### 1-Usul: Brauzerda To'g'ridan-to'g'ri Ochish (Eng oson)
* Papkadagi `index.html` faylini istalgan brauzerda (Chrome, Edge, Firefox, Safari) ikki marta bosib oching.
* Hech qanday server yoki o'rnatish shart emas!

### 2-Usul: Python yoki VS Code Live Server
Terminalda loyiha papkasida:
```bash
python -m http.server 8000
```
Brauzerda: `http://localhost:8000` manziliga kiring.

### 3-Usul: GitHub Pages (Global Internetga Chiqarish)
1. Kodni GitHub-dagi repository-ingizga joylang.
2. Repository sozlamalariga kiring: `Settings` → `Pages`.
3. `Branch` bo'limida `main` (yoki `master`) va `/root` papkasini tanlab, `Save` tugmasini bosing.
4. Saytingiz butun dunyoga bepul tarzda ochiladi: `https://<foydalanuvchi-nomi>.github.io/<repo-nomi>/`.
