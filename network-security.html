1-Dars • Tarmoq Tushunchalari

Kompyuter Tarmoqlari va Axborot Xavfsizligi Asoslari

🎯 Tarmoq Xavfsizligi Nima?

Tarmoq xavfsizligi (Network Security) — bu kompyuter tarmoqlari infratuzilmasi, uskunalar va ularda aylanuvchi ma'lumotlarni ruxsatsiz kirish, o'zgartirish, yo'q qilish yoki xizmat ko'rsatishni to'xtatib qo'yish (DDoS) kabi kiberhujumlardan himoyalashga qaratilgan qoidalar, dasturlar va uskunalar majmuidir.

🌐 IP Manzil (Mantiqiy adres)

Tarmoqdagi har bir qurilmaning raqamli pasporti. IPv4 (masalan, 192.168.1.1) va zamonaviy 128-bitli IPv6. Xakerlar ko'pincha soxta IP yuborish (IP Spoofing) orqali hujum qiladi.

🏷️ MAC Manzil (Jismoniy adres)

Tarmoq kartasining (NIC) ishlab chiqaruvchi tomonidan berilgan o'zgarmas 48-bitli apparat kodi (masalan, 00:1A:2B:3C:4D:5E). Mahalliy tarmoqda paketlar aynan MAC bo'yicha yetkaziladi.

🚪 Portlar (Port Numbers)

Kompyuterda ishlayotgan qaysi dastur ma'lumot olayotganini bildiruvchi mantiqiy darvoza (0 dan 65535 gacha). Masalan: 80 (HTTP), 443 (HTTPS), 22 (SSH), 53 (DNS).

⚠️ Tarmoqdagi Asosiy Zaiflik Nuqtalari

Tarmoq ma'lumotlar oqimi orqali ishlaydi. Agar trafik shifrlanmagan bo'lsa, xaker Sniffing (Wireshark) dasturlari yordamida tarmoqdagi barcha parollar va shaxsiy ma'lumotlarni tutib olishi mumkin.

⚠️

Muhim Xavfsizlik Qoidasi

Qurilmalaringizda foydalanilmayotgan barcha ochiq portlarni (masalan: Telnet port 23, FTP port 21) zudlik bilan yoping! Ochiq port — xaker uchun eshigi qulflanmagan xonadir.

2-Dars • Tarmoq Modellari

TCP/IP va OSI 7 Pog'onali Modeli Tahlili

🏛️ OSI Modeli (Open Systems Interconnection)

Xalqaro standartlashtirish tashkiloti (ISO) tomonidan yaratilgan ushbu model ma'lumotlarning bir kompyuterdan ikkinchisiga o'tish jarayonini 7 ta mantiqiy pog'onaga bo'ladi:

OSI 7 Pog'onali Modeli va Xavfsizlik Xaritasi 
Pog'ona # | Nomi (Layer)         | Protokollar       | Asosiy Xavf & Himoya
---------------------------------------------------------------------------------
7         | Amaliy (Application) | HTTP, DNS, SMTP   | XSS, SQLi, Phishing -> WAF
6         | Taqdimot (Presentation)| TLS/SSL, JPEG    | Ma'lumot shifrlash (HTTPS)
5         | Seans (Session)      | NetBIOS, RPC      | Hijacking -> Token xavfsizligi
4         | Transport            | TCP, UDP          | SYN Flood -> Stateful Firewall
3         | Tarmoq (Network)     | IP, ICMP, IPsec   | IP Spoofing, Ping Flood -> Router ACL
2         | Kanal (Data Link)    | Ethernet, Wi-Fi   | ARP Poisoning, MAC Spoofing -> DAI
1         | Jismoniy (Physical)  | Kabel, Radioto'lqin| Kabelni kesish, tinglash -> Jismoniy nazorat

⚡ TCP va UDP Farqi

TCP (Transmission Control Protocol): Ishonchli, ulanish o'rnatuvchi protokol. Ma'lumot uzatilishidan oldin "3-tomonlama salomlashish" (3-Way Handshake: SYN -> SYN-ACK -> ACK) bajariladi. Xatoliklar tekshiriladi.

UDP (User Datagram Protocol): Ulanishsiz, tezkor protokol. Oqimli video, onlayn o'yinlar va DNS uchun ishlatiladi. Paket yo'qolsa qayta so'ralmaydi.

💡

Hujum Misoli: TCP SYN Flood

Xaker serverga millionlab soxta SYN so'rovlarini yuboradi, ammo yakuniy ACK tasdig'ini jo'natmaydi. Natijada serverning barcha xotira navbati to'lib qoladi va haqiqiy foydalanuvchilar saytga kira olmay qoladi (DoS hujumi).

3-Dars • Perimetr Himoyasi

Firewall (Tarmoqlararo Ekran) Qanday Ishlaydi?

🛡️ Firewall Vazifasi

Firewall — bu ichki ishonchli tarmoq (masalan, ofis yoki uy tarmog'i) bilan tashqi ishonchsiz tarmoq (Internet) o'rtasidagi chegara postidir. U barcha o'tayotgan paketlarni tekshiradi va belgilangan xavfsizlik qoidalari (Ruleset) asosida o'tkazadi yoki bloklaydi.

1. Paket Filtrlash (Stateless)

Har bir paketning sarlavhasidagi manba IP, maqsad IP va port raqamiga qaraydi. Ulanish tarixini eslab qolmaydi.

2. Stateful Inspection (Holatli tekshiruv)

Ulanishlar sessiyasini kuzatib boradi. Agar ichkaridan tashqariga so'rov chiqmagan bo'lsa, tashqaridan kelgan shubhali javob paketini avtomatik bloklaydi.

3. WAF (Web Application Firewall)

7-Amaliy pog'onada ishlaydi. Veb-saytlarga kelayotgan SQL Injection va XSS hujumlarini bevosita HTTP so'rovlar ichidan aniqlab zararsizlantiradi.

Linux UFW / Iptables Firewall Qoidasi Namunasi 
# Standart qoida: barcha kiruvchi trafikni bloklash, chiquvchiga ruxsat berish
sudo ufw default deny incoming
sudo ufw default allow outgoing

# Faqat xavfsiz portlarga ruxsat berish
sudo ufw allow 22/tcp    # SSH masofaviy boshqaruv
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS xavfsiz veb

# Firewallni ishga tushirish
sudo ufw enable
4-Dars • Xavfsiz Aloqa

VPN, DNS Xavfsizligi va HTTPS Protokoli

🔒 VPN (Virtual Private Network) Nima?

VPN — bu ochiq internet ustidan shifrlangan maxfiy "tunnel" qurish texnologiyasidir. Siz kafe yoki aeroportdagi ochiq Wi-Fi tarmog'iga ulanganda, xakerlar oraliqdagi trafigingizni ko'ra olmaydi, chunki barcha ma'lumotlar to'liq shifrlangan holatda VPN-serverga yetkaziladi.

🌐 DNS va Uning Zaifliklari (DNS Spoofing)

DNS (Domain Name System) — internetning telefon kitobidir. U kun.uz kabi nomlarni 185.178.208.10 kabi IP manzilga aylantiradi. Agar kiberjinoyatchi sizning DNS so'rovingizni soxtalashtirsa (DNS Cache Poisoning), siz haqiqiy bank sayti manzilini yozsangiz ham, xakerning soxta nusxa saytiga tushib qolishingiz mumkin!

Himoya: DNSSEC (DNS Security Extensions) va DoH (DNS over HTTPS) texnologiyalari orqali DNS so'rovlarini kriptografik himoyalash.

🔐 HTTPS va TLS 1.3

HTTPS brauzeringiz va veb-server o'rtasidagi har bir baytni TLS (Transport Layer Security) protokoli orqali shifrlaydi. Brauzerda yashil qulf belgisi ko'rinishi saytning raqamli sertifikati (SSL Certificate) haqiqiy ekanligini bildiradi.

5-Dars • Simsiz Tarmoqlar

Wi-Fi Xavfsizligi va WPA3 Standarti

📡 Wi-Fi Xavfsizlik Standartlari Tarixi

  • WEP (Wired Equivalent Privacy): 1997-yil. Bugungi kunda mutlaqo yaroqsiz — bir necha daqiqada ochiladi.
  • WPA: Vaqtinchalik takomillashtirish, baribir zaif.
  • WPA2-PSK (AES): 2004-yildan beri eng keng tarqalgan standart. Biroq KRACK (Key Reinstallation Attack) zaifligiga ega.
  • WPA3 (Zamonaviy Oltin Standart): 192-bitli xavfsizlik darajasi, SAE (Simultaneous Authentication of Equals) protokoli orqali parolni offline rejimda lug'at orqali taxmin qilish (Dictionary Attack) imkoniyatini yo'qqa chiqaradi.

⚠️ Ommaviy Ochiq Wi-Fi Xavflari ("Evil Twin" Hujumi)

Xaker kafeda o'tirib o'z noutbukida "KAFE_BEPUL_WIFI" nomli soxta Wi-Fi nuqtasini ochadi. Odamlar unga ulanganda, barcha kiritilgan parollar, chatlar va shaxsiy ma'lumotlar xakerning ekranida ko'rinadi.

✅

Uy Wi-Fi Routeri Uchun 5 Muhim Qoida

1. Routerning standart admin / admin parolini o'zgartiring.
2. Shifrlash turini WPA3-Personal yoki WPA2-AES qilib sozlang.
3. Wi-Fi parolini kamida 14 ta belgidan iborat qiling.
4. Router dasturiy ta'minotini (Firmware) muntazam yangilab boring.
5. WPS (Wi-Fi Protected Setup) funksiyasini o'chirib qo'ying (u orqali parolni 4 soatda buzish mumkin).
